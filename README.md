# OOPS Using C++

A collection of beginner-friendly C++ programs for learning Object-Oriented Programming (OOP).

## Topics Covered
1. Basics of C++ – Classes and Objects
2. Constructors and Destructors
3. Static Data Members and Member Functions
4. Friend Functions
5. Inheritance

## Language and Tools
- Language: C++
- Editor: Code::Blocks
- Platform: GitHub

## Objective
To strengthen C++ and OOP fundamentals through simple programs and hands-on practice.

> Add your own explanations and practice programs as you learn.
